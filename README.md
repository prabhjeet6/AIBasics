Deep agents are advanced AI agents designed to handle complex, long-running tasks like autonomous software development or 
expensive research-over extended time horizons.

Agent Harness is infrastructure, interface and execution layer that wraps around a core AI model to turn it into an active, 
functional worker.
example Agent Harness: cline (opensource)

cline + Model(eg free open source model for coding ) gives a peer programmer agent locally.

Context refers to combination of system instructions,active tools like MCP server's data files and conversation memory packed
into AIs brain at any given moment.

An MCP adaptor is a software translation bridge that converts non-compatible tools, frameworks or platforms into the standard
MCP format so AI agents can use them instantly.
